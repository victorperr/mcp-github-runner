# Security policy

## Reporting a vulnerability

Please **don't open a public issue**. Report it privately through GitHub:
**Security → Report a vulnerability** on this repository (private vulnerability reporting).

Include what you found, how to reproduce it, and what an attacker could do with it. You'll get an answer within 5 working days.

## Scope

In scope: the gateway (`gateway/`), the runner and Action (`action/`), and the template workflow (`template/`).
The threat model, controls and known remaining risks are in [docs/security.md](docs/security.md).

## Supported versions

Only the latest release gets security fixes while the project is pre-1.0.
